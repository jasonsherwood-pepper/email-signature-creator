    Logo

    The logo always sits on top, with the details left-aligned below it. A custom URL must be a direct, public https PNG. Gmail and Outlook strip embedded images and SVGs, and Google Drive links don't work.

    Font

    Signatures use Instrument Sans with Arial as the fallback. Email can't load web fonts, so recipients only see Instrument Sans if it's installed on their device. Everyone else, including most Gmail readers, sees Arial. Install it on team computers from fonts.google.com.

    Social channels

    Host 40×40 PNGs named linkedin.png, x.png, instagram.png, facebook.png, youtube.png, tiktok.png in this folder.

    Company channels below can be added to anyone's signature with one checkbox.

    Distribute

    Each person gets a personal link that opens only their signature, with a one-click copy button and setup steps for their email app. Links always show the latest saved details, so after a fix just ask them to copy again; the link stays the same.

    Backup

    Everything is saved automatically to the team database. Export makes a file copy; Import adds or updates people from a backup and never deletes anyone.

      Install it

      1. Click Copy signature above.
      2. In Gmail on the web, click the gear icon → See all settings.
      3. On the General tab, scroll to Signature → Create new, name it (e.g. "Pepper").
      4. Click into the box and paste (⌘V / Ctrl+V).
      5. Under Signature defaults, choose it for new emails and on reply/forward.
      6. Scroll to the bottom and click Save Changes.

      If the logo shows as a broken box after pasting, the logo URL isn't public. Fix it in Brand settings and copy again.

      New Outlook for Windows, Outlook for Mac, and Outlook on the web.

      1. Click Copy signature above.
      2. Open Settings (gear) → Accounts → Signatures.
      3. Click + New signature, give it a name, and paste into the editor.
      4. Set it as the default for new messages and replies/forwards for your hellopepper.com account.
      5. Click Save.
      1. Click Copy signature above.
      2. In Outlook: File → Options → Mail → Signatures…
      3. Click New, name it, then paste into the edit box.
      4. On the right, pick your hellopepper.com account and set New messages and Replies/forwards.
      5. Click OK.

      Alternative: click Download .htm, quit Outlook, and drop the file into %APPDATA%\Microsoft\Signatures. It then appears in the signature list.

      1. Click Copy signature above (Safari or Chrome both work).
      2. In Mail: Mail menu → Settings… → Signatures.
      3. Select your hellopepper.com account in the left column and click +.
      4. Uncheck "Always match my default message font", or Mail strips the styling.
      5. Select the placeholder text in the right-hand box and paste.
      6. Choose it in the Choose Signature menu below, then close the window.

      The logo may appear as a "?" in the settings window. It displays correctly in sent mail.

      Gmail app (iPhone & Android)

      The Gmail app uses your web signature automatically, as long as its own Mobile signature setting is left empty or switched off (Gmail app → Settings → your account → Mobile signature).

      iPhone / iPad Mail app

      1. Open your personal link on the phone and tap Copy signature.
      2. Go to Settings → Apps → Mail → Signature.
      3. Delete "Sent from my iPhone" and paste.

      iOS sometimes drops formatting on paste. If it looks off, use Copy plain text instead.
